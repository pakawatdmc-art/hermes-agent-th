# Hermes ภาษาไทย

รุ่นภาษาไทยโดยชุมชนของ [Nous Research / Hermes Agent](https://github.com/NousResearch/hermes-agent)
เพิ่มคำแปลสำหรับ Desktop และ Terminal พร้อมปรับการแสดงผลสระและวรรณยุกต์ไทย
ใช้ระบบเอเจนต์ของ Hermes เดิม และเผยแพร่ภายใต้ [MIT License](LICENSE)
โครงการนี้ยังไม่ได้รับรองเป็นรุ่นภาษาไทยทางการจาก Nous Research

คู่มือนี้ติดตั้งจากซอร์สของ [pakawatdmc-art/hermes-agent-th](https://github.com/pakawatdmc-art/hermes-agent-th)
บน **macOS Apple Silicon** ซึ่งเป็นระบบที่ใช้ทดสอบรุ่นไทย
ยังไม่มีตัวติดตั้ง Desktop ที่ลงนามสำหรับแจกจ่าย; Windows และ Linux ยังไม่ได้ทดสอบสำหรับรุ่นนี้

## 1. เตรียมเครื่อง

ต้องมีอินเทอร์เน็ต พื้นที่ว่างสำหรับเครื่องมือและ dependencies รวมทั้ง **Git, Git LFS และ Xcode Command Line Tools**
ตรวจเครื่องมือใน Terminal ได้ดังนี้:

```bash
git --version
git lfs version
xcode-select -p
```

หากยังไม่มีเครื่องมือพัฒนาของ Apple ให้รัน `xcode-select --install` แล้วติดตั้งตามหน้าจอ
หากยังไม่มี Git LFS ให้ติดตั้งจาก [Git LFS](https://git-lfs.com/) แล้วรัน `git lfs install`
Hermes PM จะจัดหา Python, Node.js และเครื่องมือเวอร์ชันที่โปรเจกต์กำหนดให้

## 2. ดาวน์โหลดและติดตั้งรุ่นไทย

เปิด Terminal ในโฟลเดอร์ที่ต้องการเก็บโปรเจกต์ แล้วรันทีละบรรทัด:

```bash
git clone https://github.com/pakawatdmc-art/hermes-agent-th.git
cd hermes-agent-th
git lfs pull
./dev setup
./dev npm ci
./dev npm run build --workspace ui-tui
./dev desktop-build
```

ครั้งแรกต้องดาวน์โหลดและ build หลายส่วน จึงอาจใช้เวลาหลายนาที
หากขั้นตอนไหนรายงานข้อผิดพลาด ให้แก้ขั้นตอนนั้นก่อนรันขั้นถัดไป
`./dev` เลือก environment และพื้นที่ข้อมูล `.hermes-dev/` ของ checkout นี้ให้โดยอัตโนมัติ

## 3. เลือกภาษาไทยและเชื่อมโมเดลของคุณ

```bash
./dev hermes config set display.language th
./dev hermes model
```

เลือกผู้ให้บริการและโมเดลที่คุณมีสิทธิ์ใช้งาน แล้วเข้าสู่ระบบหรือใส่ API key ตามขั้นตอนของผู้ให้บริการ
หากใช้สมาชิก ChatGPT หรือ Codex ให้เลือก **ChatGPT or Codex Subscription** และยืนยันบัญชีของคุณเอง
ชื่อโมเดลที่เลือกได้ขึ้นกับบัญชีและผู้ให้บริการ ดู [คู่มือผู้ให้บริการ](website/docs/integrations/providers.md)
ประกอบได้ ค่าใช้จ่ายและสิทธิ์ใช้งานโมเดลเป็นไปตามบริการที่คุณเลือก

การเลือกภาษา UI เปลี่ยนข้อความบนหน้าจอ หากต้องการคำตอบภาษาไทย ให้บอกในคำสั่ง เช่น “ตอบเป็นภาษาไทย”
หรือเลือกใช้บุคลิกไทยที่เตรียมไว้ ระบบเตรียม `SOUL.md` เริ่มต้นให้แล้ว
คำสั่งต่อไปนี้สำรองไฟล์เดิมก่อนแทนที่ด้วยแม่แบบไทย:

```bash
cp -p .hermes-dev/SOUL.md ".hermes-dev/SOUL.backup-$(date +%Y%m%d-%H%M%S).md"
cp local-dev/SOUL.th.md .hermes-dev/SOUL.md
```

บุคลิกมีผลกับบทสนทนาใหม่ หากปรับบุคลิกไว้เองแล้ว
ให้เปิดไฟล์เพื่อผสานคำแนะนำภาษาไทยตามต้องการแทนการแทนที่ทั้งไฟล์

## 4. เปิดใช้งาน

Desktop:

```bash
./dev desktop
```

Terminal แบบ TUI:

```bash
./dev terminal
```

หลังติดตั้งและ build แล้ว บน Mac สามารถดับเบิลคลิก `เปิด Hermes Desktop.command`
หรือ `เปิด Hermes Terminal.command` ใน Finder ได้
ไฟล์ `.command` เปิดผ่าน Terminal

หากต้องการเปิด Desktop โดยไม่แสดง Terminal ให้สร้างตัวเปิดสำหรับเครื่องของคุณหลัง build สำเร็จ:

```bash
./dev python local-dev/install_macos_launcher.py
```

ตัวเปิดจะอยู่ในโฟลเดอร์ `Applications` ภายในโฟลเดอร์ผู้ใช้ ชื่อ **Hermes ภาษาไทย.app**
เปิด Finder ไปยังโฟลเดอร์นั้น เลือกแอป แล้วใช้ **ไฟล์ → เพิ่มไปยัง Dock**
ตัวเปิดนี้สร้างจากซอร์สบนเครื่องคุณ ใช้ Xcode Command Line Tools และไม่ได้รับการลงนาม Developer ID หรือ notarization
หากย้ายโฟลเดอร์โปรเจกต์ ให้รันคำสั่งสร้างตัวเปิดใหม่เพื่อปรับพาธ

ใน Desktop เปลี่ยนภาษาได้ที่ **การตั้งค่า → รูปลักษณ์ → ทั่วไป → ภาษา → ไทย**
ใช้ `./dev` ต่อเนื่องเพื่อให้ Desktop และ Terminal เลือกพื้นที่ข้อมูลชุดเดียวกัน

## 5. ทดลองงานแรก

กด **บทสนทนาใหม่** แล้วลองพิมพ์:

> ช่วยวางแผนงานวันนี้ให้ฉัน ถามทีละคำถาม แล้วสรุปเป็นรายการที่ทำตามได้ ตอบเป็นภาษาไทย

หากต้องการอ่านไฟล์ ใช้ปุ่ม **แนบ** หรือระบุพาธไฟล์ให้ชัดเจน แล้วบอกผลลัพธ์ที่ต้องการ เช่น:

> อ่านไฟล์บันทึกประชุมนี้ แล้วสรุปเป็น 5 ข้อ พร้อมตารางผู้รับผิดชอบและกำหนดส่ง อ้างอิงจากไฟล์เท่านั้น

ตรวจรายละเอียดเมื่อมีคำขออนุญาตใช้เครื่องมือ และตรวจทานข้อมูลสำคัญในคำตอบกับต้นฉบับ

## ข้อมูลและการอัปเดต

- การตั้งค่า บัญชีที่เชื่อม ประวัติสนทนา และ logs อยู่ใน `.hermes-dev/` ของคุณ ซึ่งถูกยกเว้นจาก Git
- ผู้ใช้แต่ละคนเชื่อมบัญชีของตัวเอง ซอร์สที่ดาวน์โหลดไม่มีบัญชีหรือประวัติสนทนาของผู้พัฒนา
- ก่อนอัปเดต ให้จบงานและปิดทั้งสองหน้าจอ แล้วรัน `./dev hermes gateway stop`
- หาก checkout ไม่มีการแก้โค้ดค้างไว้ ใช้คำสั่งด้านล่างเพื่อรับรุ่นไทยล่าสุดและ build ใหม่:

```bash
git pull --ff-only origin main
./dev setup
./dev npm ci
./dev npm run build --workspace ui-tui
./dev desktop-build
```

หาก Git แจ้งว่ามีไฟล์แก้ค้างหรือ branch แยกกัน ให้เก็บงานของคุณก่อนรวมการอัปเดต
สำหรับ fork นี้ให้ใช้ขั้นตอน Git ข้างบนเพื่อรับซอร์สจาก `pakawatdmc-art/hermes-agent-th`

## เมื่อพบปัญหา

- **Desktop แจ้งว่าไม่มี build:** รัน `./dev npm ci` และ `./dev desktop-build` ให้สำเร็จก่อนเปิด
- **ยังเห็นภาษาอังกฤษหลังตั้งค่า:** ปิด Desktop/TUI แล้วรัน `./dev hermes gateway stop` ก่อนเปิดใหม่
  ชื่อโมเดล คำสั่ง ผลจากเครื่องมือภายนอก และเมนูระบบบางส่วนยังเป็นอังกฤษได้
- **เชื่อมโมเดลไม่ได้:** เปิด `./dev hermes model` เพื่อตรวจผู้ให้บริการและบัญชีที่เลือก
- **ต้องการตรวจสภาพแวดล้อม:** ใช้ `./dev doctor` และ `./dev hermes pm doctor`
- แจ้งปัญหารุ่นไทยที่ [Issues](https://github.com/pakawatdmc-art/hermes-agent-th/issues)
  พร้อมระบบปฏิบัติการ ขั้นตอนที่ทำ และข้อความผิดพลาด โดยลบ token, API key และข้อมูลสนทนาส่วนตัวก่อนแนบ
